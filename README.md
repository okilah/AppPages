# AppPages

Static, standalone legal/support pages hosted via GitHub Pages for various apps — Privacy Policy / Terms of Use URLs that App Store Connect requires but that the apps themselves don't host anywhere.

Each page lives in its own top-level folder as `index.html`, so it gets a clean URL once GitHub Pages is enabled for this repo.
